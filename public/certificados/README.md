# Certificados de presentación

Agregar los PDF con estos nombres exactos:

- `conaiisi-2025.pdf`: certificado de presentación en CONAIISI 2025.
- `wicc-2026.pdf`: certificado de presentación en WICC 2026.

La ficha del proyecto MCP muestra automáticamente cada enlace cuando su archivo existe. Ejecutar nuevamente el build y desplegar después de agregarlos. No hace falta modificar JSX. Revisar que cada certificado corresponda a esta investigación y que sea adecuado para publicación pública.
